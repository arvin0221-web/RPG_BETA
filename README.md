# 製杖 RPG (WandCraft RPG)

歡迎來到 **製杖 RPG** 的 GitHub 官方頁面。這是一款專為網頁開發的極簡風格 RPG 遊戲，目前正處於 BETA 測試階段。

## 📝 關於遊戲
**製杖 RPG** 是一款追求純粹機制與技術實踐的網頁遊戲專案。玩家可以直接透過瀏覽器體驗戰鬥系統與角色養成，無需下載任何檔案。

### 遊戲特色：
*   **網頁即開即玩**：基於 HTML/JavaScript 開發，完美支援各類瀏覽器。
*   **開源專案**：代碼託管於 GitHub，公開透明的開發進程。
*   **持續更新**：目前為 BETA 版本，針對 RPG 核心邏輯進行不斷優化。
